# Capital Fortune UI reference

This implementation follows the user-confirmed mobile UI templates and core layout.

## Canonical shell
- Portrait-first mobile layout.
- Top HUD: player identity placeholder, current click level, cash balance, and menu.
- Bottom navigation: Assets, Markets, Tap, Empire, Corp.
- Purple neon / midnight surfaces with premium gold interaction accents and green positive financial values.

## Screen mapping
- Tap: large central gold coin interaction, per-tap earnings, level indicator, performance metrics, and upgrade list.
- Assets: consolidated cash, business, property, stock, crypto, collectible, and casino-chip values.
- Markets: existing stock and cryptocurrency trading workflows.
- Empire: existing business, real estate, research, collectibles, casino, achievements, and statistics screens retained as nested sections.
- Corp: honest connected-service placeholder; no corporation membership or contribution backend is fabricated.
- Profile and Settings: reachable from the HUD menu; profile is derived from local save data and settings explains which preference controls remain to be connected.

The supplied generated images are visual specifications. Functional Compose components are used rather than embedding static screenshots as interactive UI.
